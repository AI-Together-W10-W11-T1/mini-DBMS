## 필요할 때 쓰는 구성과 계속 보류할 것

RTK는 긴 출력에 선택 사용하고 Graphify는 구조 탐색·작업 끝 색인에 쓴다. Wiki는 검증한 새 결정/실패만 원문과 대조해 기록한다. 플러그인은 현재 세션 실제 기능과 필요성이 있을 때 사용하며 기존 전역 연결을 삭제하지 않는다.

TypeScript·Node·npm 및 새 MCP는 도입하지 않는다. Playwright Test/Node worker, Context7·Superpowers·Ponytail·벡터/Modular RAG·fine-tuning은 구체 병목 확인 전 보류한다. 추가 유료 API/구독/자동 과금도 도입하지 않는다.

원본 `codex-setup-github/export.py`·`restore.py`는 현재 C 프로젝트 이식 도구로 갱신하지 않았다. 원본 restore를 현재 루트에 일괄 적용하면 과거 구성을 가져올 수 있으므로 별도 이식 작업 없이 사용하지 않는다.
